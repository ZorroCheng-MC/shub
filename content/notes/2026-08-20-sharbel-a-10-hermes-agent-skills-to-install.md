## 🧠 Core Concepts

- **Input tokens persist**: anything the agent reads stays in context and is re-sent every turn — so trimming *what goes in* (Defuddle) compounds.
- **Output is the expensive side**: output costs several× input *and* becomes part of the conversation, re-billed every subsequent turn — hence Caveman's compression matters more than it sounds.
- **Index once, query forever**: Codebase Memory turns repeated file reads into one graph lookup (~95–99% fewer exploration tokens).
- **Skills vs platforms vs MCP**: some entries aren't skill files — Codebase Memory and Composio are servers/platforms; the *effect* (an installable capability) is the same.
- **Ability vs judgment**: Marketing Skills adds *judgment* (what a good landing page/subject line does), not just tools.
- **From chatbot to team**: Oh My Claude Code decomposes → assigns specialists → runs pipelines → **verifies**, fixing the "agreeable liar" failure mode; Superpowers is the framework/OS layer.
- **Curation is the real skill**: skills are free; the cost is diluting the good ones under dozens you never use.

## 📝 My Learning Notes

### Key Insights

- The three "cheaper" skills attack the three token sinks: **inbound reading** (Defuddle), **outbound writing** (Caveman), **codebase exploration** (Codebase Memory) — together they hit the biggest cost centers.
- **Verification is the missing layer** in single-agent setups; the "team" skills exist to stop confidently-wrong answers on irreversible work.
- Author's discipline with big skills (Humanizer, 29.6 KB): **invoke late, invoke once**, do the pass in a fresh session — because a large skill sits in context for the whole session.
